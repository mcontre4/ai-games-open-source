# Creation speed

Create and Modify offer Regular (the default), Fast and Ultra fast. Requests accept `speed: regular | fast | ultra-fast`; omitted speed defaults to Regular, including installed clients using the older API. Jobs persist the choice and retries inherit it. Existing jobs are migrated to Ultra fast to retain the previously deployed global policy.

The worker uses `OPENROUTER_CODING_MODEL` (currently `openai/gpt-6.1-sol`) and the saved job speed for game planning, Codex coding and visual quality review. Regular omits `service_tier` and `speed` entirely. Fast uses `service_tier=priority`; Ultra fast uses `service_tier=ultrafast`. Premium tiers discover healthy tool-capable endpoints and their conservative prices before any paid work and pin the approved endpoint tags. Each gateway grant retains its own client/model, so concurrent jobs cannot change each other's routing. Model-generated routing overrides never replace server policy. Moderation and Muse images keep their own models and ordinary routing. The old global `OPENROUTER_SERVICE_TIER` environment variable is no longer used.

The UI describes standard, faster and fastest AI responses without promising a fixed game completion time. Planning, image generation, tool calls, compilation and validation all contribute to the wait. No paid timing benchmark was run for this change.

The [Sol endpoint catalog](https://openrouter.ai/api/v1/models/openai/gpt-6.1-sol/endpoints), checked on 2026-10-12, lists ordinary OpenAI input/output rates of $2/$10 per million tokens, Fast $4/$20 and Ultrafast $12/$60. The selector therefore explains approximately 2× (+100%) and 6× (+500%) AI token costs compared with Regular. These are token-rate comparisons, not total-game quotes; artwork, input/output volume, caching and endpoint pricing affect the bill. Published long-context overrides remain part of conservative reservations. See [OpenRouter service tiers](https://openrouter.ai/docs/guides/features/service-tiers), [OpenAI Fast mode](https://developers.openai.com/api/docs/guides/fast-mode) and [OpenAI Ultrafast mode](https://developers.openai.com/api/docs/guides/ultrafast-mode).

Deploy migration `202610120003_generation_speed.sql` before restarting API and worker. It is additive and requires the table owner or superuser. No sandbox image or dependency change is required. Updated mobile screens require an app build/update; restarting the server alone cannot update an already-installed native bundle.

Verification uses explicitly unbilled provider fixtures, real PostgreSQL/Docker tests and the exported Expo browser app. Native verification and paid live generation for this change remain **BLOCKED**: Maestro and a development OpenRouter key are unavailable in this checkout. Neither browser fixtures nor production health checks substitute for those checks.
